## Exact import contract

u2.failure.capture.C.M.v1 identifies a statically selected ordinary aggregate
carrier C and its Text message field ordinal M. A declaration has imported kind
2, effects 63, version 1 and exact signature [payload] -> [the defined Function's
FailureContext carrier]. C must be selected with existing kind-4 value metadata
and native aggregate layout binding; M must be in range and have the exact
selected canonical Text type. Canonical source location remains mandatory.
The name does not grant type or root authority. Invalid kind/version/effects,
carrier/descriptor/signature/message/layout/source origin refuses before output.

Payload and opaque FailureContext carriers must remain distinct, as required
by existing root admission. The context carrier is inferred from the verified
checked Function contract, not supplied as another class-1 descriptor. This
profile retains one native payload binding per selected canonical shape; it
does not introduce nominal-error-family/source fails-clause lowering. Payload
field families/caps are those of the existing aggregate profile (32 fields,
eight selected carriers). Full typed source routing remains a later boundary.

The generated instruction uses evn_frame/setjmp, evn_fail with the verified
message ordinal, evn_pop and evn_saved. These existing helpers own typed payload
snapshot/capture, allocation, global failure state and saved-context lifetime.
The catch is local to this constructor; successful completion yields a context,
not a checked branch. Checked propagation still uses original opcode 47.

Original live-before roots protect the payload throughout capture. Immediately
after evn_saved returns, store the pointer in the existing third class-5 temporary
word and original result SSA slot, before erist_rt_failure_clear. Independently
verified live-after publication then precedes temporary retirement. Existing
class-1 temporary words are unchanged. No new frame/root layout or GC authority.
Preserve the original canonical instruction/LocId; no synthesized executable
operation or native location record is made. The saved runtime representation
is unchanged; this does not add the reference context's location/trace fields.

Only checked entries with selected aggregate payloads inspect this import family.
Old profiles retain their import path without an extra intermediate Target.
List bounds emission remains limited to actual List kinds; message ordinals
4/6 must not classify failure constructors as List operations. No benchmark

Allocation/invalid-state defects remain terminal runtime faults. The constructor
cannot convert allocation refusal into a fabricated checked context. Saved
